# GeeHaw Diesel & Equipment Repair — Demo 2

A responsive four-page website concept by LIT America.

Plain HTML, CSS and JavaScript. No build step, paid templates, API keys, tracking or subscription dependencies.

## Preview

Open index.html or serve this directory with a static web server.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, then main and /(root), and Save.

## Content

Based in Alamo, Tennessee; serving the Jackson area. Business phone: 731-225-9722. Engine brands describe work performed, not certification or dealership affiliation. Hours, prices, availability and certifications are not invented.

The contact helper prepares a text message; the visitor reviews it and opens their own messaging app to send. There is no backend form submission or stored customer data.

The truck artwork is a custom SVG illustration, not a photograph of the business's equipment. Replace with owner-approved work photos when available.

Search indexing is disabled for this demo. Remove the noindex,nofollow meta tag only when preparing the approved production site.
