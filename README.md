# GeeHaw Diesel & Equipment Repair

A service-focused website by LIT America for 24/7 mobile heavy-duty diesel repair, tire changes, and DPF troubleshooting in Jackson, Tennessee. Based in Alamo. Call 731-225-9722.

## Hosting
Static HTML, CSS and JavaScript. No build step, subscriptions, external fonts, trackers, paid assets, or API keys. For GitHub Pages, select main and /(root) under Settings > Pages.

## Pages
Home; Services; Mobile Diesel Repair; Mobile Tire Service; DPF & Aftertreatment; About; Service Area & Contact.

## Local search
Each page has a descriptive title, description, canonical URL, and LocalBusiness structured data with the supplied phone, Alamo locality, Jackson service area, and 24/7 hours. Includes sitemap.xml and robots.txt. No fabricated reviews, street address, response times, or certification claims. Indexing is enabled. Canonical and sitemap URLs use this repository’s GitHub Pages origin; update them together if moving to a business domain.

Search rankings are not guaranteed. A business-owned Google Business Profile, verification and Search Console setup remain separate owner-account tasks. No changes to those accounts were made.

## Contact helper
Prepares a service text for visitor review and opens their messaging app only when selected. No automatic sending, backend form submission, or customer data storage. Actual phone and SMS delivery require a real device.
